# 🍮 Flan Clicker

A clicker game where you click a piece of flan and watch it escalate into pure chaos.

## How to run

Open `index.html` directly in any browser — no build step needed.

Or serve it locally:
```bash
npx serve .
```

Then open http://localhost:3000.

## Controls

- **Click the flan** — that's it

## Levels of intensity

| Level | Clicks needed | Effect |
|-------|--------------|--------|
| 0 | 0 | Calm flan, gentle wobble |
| 1 | 1 | It wiggles |
| 2 | 5 | It shimmies, particles fly |
| 3 | 15 | JIGGLE-WIGGLES, screen flashes |
| 4 | 30 | FULL FLAN FRENZY, intense shake |
| 5 | 50 | 🍮💥 FLAN OVERLOAD — maximum chaos |

## Known limitations

- Click count resets on page refresh (no persistence)
- Mobile tap works but is not optimized
