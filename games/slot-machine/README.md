# 🎰 SIGMA SLOTS

> no cap, this is the only slot machine that matters fr fr

A brainrot-coded Gen Z slot machine built with **vanilla HTML + CSS + JS**. No frameworks. Pure chaos energy.

## 🚀 How to run

```bash
# Just open the file directly — no build step needed
open games/slot-machine/index.html

# OR serve it locally with any static server:
npx serve games/slot-machine
# then visit http://localhost:3000
```

## 🎮 Controls

| Action | How |
|--------|-----|
| Spin | Click **SPIN** button or press `Space` |
| Max Bet | Click **MAX BET (sigma move)** |
| Change bet | Click any bet amount button |
| Close overlay | Click the button on the win/loss popup |

## 🗿 Features

- Weighted symbol system (rare = higher payout)
- Neon animated UI with `@keyframes` chaos
- Floating emoji particles (ambient + on spin)
- Confetti explosion on jackpot wins
- Win/Loss overlays with random brainrot messages
- Meme banners every 5 spins
- Spin history log (W's and L's)
- Keyboard shortcut: `Space` to spin
- Responsive layout

## 🛠️ Stack

- Pure HTML5
- CSS3 (custom properties, keyframe animations, gradients)
- Vanilla JavaScript (no dependencies, no build step)
- Google Fonts: Bangers + Nunito
